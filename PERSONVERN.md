# Personvernerklæring – Sporjeger

Sist oppdatert: 19.10.26

Sporjeger har ingen innlogging og ingen brukerkontoer. Appen ber ikke om
opplysninger om deg.

## Verktøykatalogen

Appen henter verktøykatalogen fra en database hos Supabase i Stockholm (EU).

- Appen leser bare katalogen. Den sender ikke det du søker etter eller
  filtrerer på.
- Supabase får IP-adressen din og informasjon om nettleseren når appen henter
  katalogen.
- Appen lagrer en kopi av katalogen på enheten din, slik at den virker uten
  nett. Kopien inneholder ingen opplysninger om deg. Du sletter den ved å tømme
  lagrede data for nettstedet i nettleseren.

## Nettstedet

Appen ligger på GitHub Pages. GitHub får IP-adressen din når du åpner appen.

## Besøksstatistikk

Appen teller besøk med GoatCounter. Tallene viser hvor mye appen blir brukt.

- Appen sender bare adressen til startsiden, `/sporjeger_pwa/`. Søk og annet innhold sendes ikke.
- Appen lagrer ingenting på enheten din for å telle besøk.
- GoatCounter bruker IP-adressen din og informasjon om nettleseren i opptil 8 timer for å telle deg én gang. De lagres ikke.
- GoatCounter lagrer bare samlede tall. GoatCounter drives fra Irland og lagrer tallene hos Hetzner i Finland og Tyskland.
- Grunnlaget er berettiget interesse (personvernforordningen artikkel 6 nr. 1 bokstav f): Å se hvilke apper som brukes.
- Du kan unngå tellingen ved å blokkere `goatcounter.com`, for eksempel med en annonseblokkering.
